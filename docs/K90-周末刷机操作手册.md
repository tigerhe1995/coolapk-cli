## 一、周末当天流程

### 阶段 0：准备（30 分钟）

```
□ 0.1 手机充满电，笔记本插电源
□ 0.2 数据线（原装或好的 USB3.0 线），台式机用机箱后置口
□ 0.3 手机开启：开发者选项 → USB调试 + USB调试(安全设置)
□ 0.4 关闭杀毒软件/防火墙（工具箱作者声明是误报）
□ 0.5 电脑上先跑一次检查：scripts\00-检查清单.ps1
□ 0.6 跑快照：scripts\01-刷机前快照.ps1
□ 0.7 ★ 手动拨号截图存档：
        *#06#        → IMEI
        *#*#6488#*#* → MIUI 码
        截图存到 files\04-备份\
```

### 阶段 1：解锁 BL（20 分钟）

```
□ 1.1 用临时root工具提权（GhostLock / DirtyFrag 之类）
□ 1.2 打开 KSU 管理器 → 超级用户 → 找到 shell → 给 root 权限
□ 1.3 双击「双击我打开Xiaomi-QC解锁BL工具v2.5Plus.exe」
□ 1.4 选机型 K90（8E系）→ 选「已有root」路线 → 一键解锁
□ 1.5 ★ 花屏/白屏 → 等 10 秒，别拔线
□ 1.6 手动进 fastboot：长按开机键黑屏 → 同时按 音量下+开机键 → 松手
□ 1.7 验证：fastboot getvar unlocked  →  必须是 unlocked=yes
```

**如果 1.7 不通**（unlocked=no 或仍在锁定）：
```
→ 走备选路线：工具箱里的 K90 官方 gpt_both4.bin + 9008 免授权引导
→ 或用 files\02-K90工程小包 的 rawprogram0-5.xml 走 OneToolBox 写分区
```

### 阶段 2：线刷官方包（30 分钟）

```
□ 2.1 cd /d F:\04.DSH\work\k90-root\files\03-官方线刷包\已解压\annibale_images_OS4.0.6.0.XPKCNXM_17.0
□ 2.2 ★★★ flash_all.bat        （清数据）
        绝对不要选 flash_all_lock.bat
        路径不能有空格和括号
□ 2.3 等待刷完，最后一行出现 fastboot reboot
□ 2.4 手机自动重启进系统
```

**卡在 fastboot / 无限重启**：
```powershell
cd F:\04.DSH\work\k90-root\tools\platform-tools
fastboot flash partition:4 ..\..\files\03-官方线刷包\已解压\annibale_images_OS4.0.6.0.XPKCNXM_17.0\images\gpt_both4.bin
fastboot erase userdata
fastboot erase metadata
fastboot reboot
# 还不行就切槽位
fastboot --set-active=a
fastboot --set-active=b
```

### 阶段 3：备份字库（必做，10 分钟）

```
□ 3.1 开 USB 调试连上电脑
□ 3.2 powershell -ExecutionPolicy Bypass -File scripts\02-字库备份.ps1
□ 3.3 确认输出「成功 N / N」
□ 3.4 ★ 把整个「字库-时间戳」目录复制到移动硬盘/网盘
```

### 阶段 4：刷 KernelSU（15 分钟）

**方式 A（推荐，工具箱引导）**
```
□ 4.1 解锁工具箱里可能有「刷入KSU」选项，跟着走
```

**方式 B（手动刷 LKM）**
```
□ 4.2 把 lkm-aarch64-android15-6.6_kernelsu.ko 推到手机
     adb push F:\04.DSH\work\k90-root\tools\kernelsu\lkm-aarch64-android15-6.6_kernelsu.ko /data/local/tmp/
□ 4.3 安装管理器
     adb install F:\04.DSH\work\k90-root\tools\kernelsu\KernelSU_v3.3.1_manager.apk
□ 4.4 在 KSU 里选「未安装 → LKM」模式，指向该 .ko 文件安装
```

**方式 C（刷 init_boot 内核版）**
```
□ 4.5 找 K90 对应的 KernelSU 内核镜像，fastboot 刷 init_boot
```

### 阶段 5：收尾（10 分钟）

```
□ 5.1 powershell -ExecutionPolicy Bypass -File scripts\04-刷机后收尾.ps1
□ 5.2 确认输出「✓ BL 已解锁」
□ 5.3 确认「✓ IMEI 与刷机前一致」
□ 5.4 重启手机，确认 root 还在（持久性验证）
□ 5.5 装 ZygiskNext（隐藏 root 环境）
     https://github.com/Dr-TSNG/ZygiskNext/releases
□ 5.6 确认系统更新已禁用
```
