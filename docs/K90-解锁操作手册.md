## 四、刷真正的内核级 KernelSU

### 4.1 方案 A：让 ksud 在手机上直接刷（最稳）

手机有 root 后，用 KSU 自带的 ksud：

```bash
# 把补丁后的 init_boot 推到手机
adb push F:\04.DSH\work\k90-root\work-patch\init_boot_ksu.img /data/local/tmp/

# 用 ksud 修补并刷入（ksud 会自动备份原厂镜像）
adb shell "su -c '/data/adb/ksu/bin/ksud boot-patch --boot /data/local/tmp/init_boot_ksu.img --partition init_boot --flash --backup'"
```

> `--backup` 会把原厂 init_boot 存到 `/data/adb/ksu/ksu_backup_<SHA1>`，
> 以后可以用 `ksud boot-restore` 一键还原。

### 4.2 方案 B：手动 fastboot 刷

```powershell
adb reboot bootloader
fastboot flash init_boot F:\04.DSH\work\k90-root\work-patch\init_boot_ksu.img
fastboot reboot
```

> ⚠️ 手动刷不会自动备份原厂 init_boot。
> 原厂镜像在：`F:\04.DSH\work\k90-root\files\04-备份\原厂镜像\init_boot_factory_a.img`
> MD5 = `7eaa18ba9fd22ff11e72e3307b558cf0`

### 4.3 验证内核级生效

重启后：

```powershell
adb shell "su -c 'grep -i kernelsu /proc/modules'"     # 应该有 kernelsu
adb shell "su -c 'ls /data/adb/ksu/lib/'"               # libksud.so 存在 = 内核级
```

**对比**：

| 特征 | LKM 临时加载（旧） | 内核级（新） |
|---|---|---|
| `/proc/modules` 有 kernelsu | ✅ | ✅ |
| `/data/adb/ksu/lib/libksud.so` | ❌（只有 libadbroot.so） | ✅ |
| 依赖漏洞提权 | 是 | 否 |
| OTA 后是否还在 | 看运气 | 在 |

### 4.4 装管理器

```powershell
adb install F:\04.DSH\work\k90-root\tools\kernelsu\KernelSU_v3.3.1_manager.apk
```

（手机上已装 SukiSU，可以不装）

## 九、常见问题

**Q：解锁后手机开不了机？**
A：99% 是刷 lk 时断电。按 7.1 / 7.2 处理。

**Q：工具箱说「未解锁~可能刷了隐藏模块」？**
A：ZygiskNext / 隐藏模块会伪装 BL 状态。正常，不影响解锁。

**Q：工具箱选项选哪个？**
A：**2**（Xiaomi-8E）。你是 8E 至尊版。

**Q：会不会变砖？**
A：会，但有三重保险：① 字库备份 ② 原厂 init_boot 备份 ③ 9008 备选包。

**Q：解锁后模块还在吗？**
A：**不在了**，线刷清 data。第五步恢复。

**Q：每次解锁都要 9008 吗？**
A：不用，8E 机型有免授权引导，工具箱能一键搞定。
