# REDMI K90 永久 Root 执行方案（字库已确认）

> 确认信息（2026-11-17，澎湃工具箱「硬件概览」）：
> **ROM 存储厂商 = 海力士 (Hynix)，型号 = `HN8T271EJKX152 X004`，代码 0x01ad，512GB**
> **RAM = 海力士 12GB**
>
> ✅ **不是铠侠**（`HN8T` 是海力士 UFS 4.x 颗粒；铠侠是 `THG*`/`THGBM*`/`THGMA*`）
> ✅ **免授权引导可以用，第一道闸门通过**

## 执行步骤

### 第 0 步：准备（30 分钟）

**0.1 备份 —— 最重要**

```powershell
# 1. IMEI / MIUI 码（防止刷机丢基带）
#    拨号盘输入 *#06# 截图保存
#    另：拨号盘输入 *#*#6488#*#* 查看 MIUI 码

# 2. 重要数据
adb pull /sdcard/DCIM C:\backup\DCIM
adb pull /sdcard/Pictures C:\backup\Pictures
adb pull /sdcard/Download C:\backup\Download
adb pull /sdcard/Music C:\backup\Music

# 3. 完整系统快照
adb shell getprop > k90_getprop.txt
adb shell uname -a > k90_uname.txt
adb shell cat /proc/partitions > k90_partitions.txt
adb shell dumpsys SurfaceFlinger --display-id > k90_display.txt
```

**0.2 下载工具**

| 资源 | 地址 | 提取码 |
|---|---|---|
| QC解锁BL工具 v2.5Plus + 资料 | `https://1812230881.share.123pan.cn/123pan/Id6rVv-BN1g3` | `mlrr` |
| K90 官方线刷包（4.0.6.0 或更高） | `https://rom.oppo.help/` | — |
| 备选资源站 | `https://moliranran.com:5245/` | — |

> 工具箱是加密压缩包，密码要「进组织获取」或私信作者（feed 74800795）。
> 资源站 `moliranran.com:5245` 通常直接可下。

**0.3 环境准备**

```
- Windows 10+，笔记本插电源
- 原装数据线（USB 3.0 更好，供电不足会刷机失败）
- 桌面机用机箱后置 USB 口，前置面板供电弱
- 关闭杀毒软件/防火墙（会拦驱动）
- 解压路径不要有空格和括号（会导致线刷失败）
```

### 第 1 步：装驱动（不用重启）

1. 双击 QC 工具箱 exe，输入密码解压
2. 工具箱里 `Tools\Driver` 目录 → 双击「一键安装安卓驱动」
3. **不需要重启**

### 第 2 步：临时root 给 shell 授权

1. 打开你现在用的临时root 工具（GhostLock / DirtyFrag 等）
2. 执行提权 → 成功
3. 打开 **KernelSU / SukiSU / BakaSU** 管理器（**必须自带 `libksud.so`**，1.10 以后版本的工具不再自带）
4. **超级用户** → 找到 **shell** → 授予 root 权限（有搜索栏）

> 找不到 shell？说明 KSU 没装或没给权限，先装一个 KSU 管理器（APK 就行）。

### 第 3 步：一键解锁

1. QC 工具箱 → 选机型 **K90**（8E 系）
2. 工具箱检测到临时root 状态 → 提示走「已有root」路线
3. 按提示执行，**过程不要拔线不要乱动**
4. 完成后手机会**花屏/白屏 10 秒**（正常现象），不要拔线
5. 10 秒后**手动进 fastboot**：长按开机键直到黑屏，再同时按 **音量下 + 开机键**，进 fastboot 松手

### 第 4 步：验证解锁

工具箱里有「查询BL解锁状态」脚本，或手动：

```bash
fastboot getvar unlocked
# 输出 unlocked=yes 就是成功
```

### 第 5 步：线刷官方包（必须）

⚠️ **这一步会清空数据**（解锁时已经清过一次，这是第二次）

```
1. 解压 K90 官方线刷包
2. 找到 flash_all.bat（★绝不能选 flash_all_lock.bat）
3. 双击运行，或 CMD 里：
   cd /d <线刷包路径>
   flash_all.bat
4. 路径不能有空格和括号
5. 刷完会自动重启，最后一行出现 fastboot reboot 就是刷完
```

**如果刷完卡在 fastboot**：

```bash
fastboot flash partition:4 mi_gpt_both4.bin
fastboot erase userdata
fastboot erase metadata
fastboot reboot
```

（`mi_gpt_both4.bin` 在解锁资料文件夹里，**强烈建议完整刷包**）

**如果无限重启进不去系统**：

```bash
fastboot --set-active=a
fastboot --set-active=b
# 或关机键+音量上进 recovery 清数据
```

### 第 6 步：刷 KernelSU（永久root）

推荐 **KernelSU 内核级 root**（不写分区、不动 boot、隐藏最强、系统升级不掉 root）。

选项：
- **A. QC 工具箱直接刷**：v2.5Plus 支持解锁后引导刷 KSU
- **B. 手动刷**：找 K90 对应的 KSU 镜像，fastboot 刷 init_boot 或内核
- **C. Magisk**：patch boot.img（通用但隐藏要额外模块）

> 酷安 K90 玩家实际配置（feed 74471671）：`root方式：ksu 内核级root更省电`

### 第 7 步：备份字库（解锁后第一件事）

字库存着基带 IMEI，**现在必须备**：

```
1. 用 Magisk/KSU 授予文件管理器 root
2. 读取 /dev/block/by-name/ 下所有含 ufs 的分区
   重点：ufs_a / ufs_b / ufs_a_1 / ufs_b_1 / ufs_a_2 / ufs_b_2
   以及 modemst1/2、fsc、persist 等
3. 备份到电脑存档
```

### 第 8 步：收尾

```
1. 关闭系统更新（解锁后 OTA 会失败/回锁）
2. 装隐藏模块：ZygiskNext / 伪造 BL 锁状态
3. 检查 Play 完整性（如需要 Google 服务）
4. 重启后再确认 root 还在（验证持久性）
```

## 备选路线（如果 A 不顺）

### 路线 B：Termux 自解锁（不用电脑）

feed 71517523 完整命令见 `docs/K90-root-research.md`。核心：

```bash
pkg install termux-usb android-tools -y
# fastboot + OTA 数据线连自己手机
termux-usb -l
termux-usb -r -e $SHELL -E /dev/bus/usb/001/002
fastboot oem set-gpu-preemption 0 androidboot.selinux=permissive
fastboot continue
adb shell getenforce
adb devices
adb push abl.elf /data/local/tmp/abl
adb shell service call miui.mqsas.IMQSNative 21 i32 1 s16 "dd" i32 1 s16 'if=/data/local/tmp/abl of=/dev/block/by-name/abl_a' s16 '/data/mqsas/log.txt' i32 60
adb shell service call miui.mqsas.IMQSNative 21 i32 1 s16 "dd" i32 1 s16 'if=/data/local/tmp/abl of=/dev/block/by-name/abl_b' s16 '/data/mqsas/log.txt' i32 60
adb reboot bootloader
termux-usb -l
termux-usb -r -e $SHELL -E /dev/bus/usb/001/002
fastboot flash partition:4 jiesuo_gpt_both4.bin
fastboot boot boot.img
# 花屏10秒后手动进 bootloader
fastboot getvar unlocked     # unlocked=yes
# 然后刷完整包
sh /storage/emulated/0/Alarms/h/k90/img/flash_all.sh
```

文件：`http://pan.ieml.cn/#s/ECroGtIL` 码 `68Rc1`
完整包：`https://hyperos.fans/`

## 风险清单

| 风险 | 等级 | 说明 |
|---|---|---|
| 解锁清空数据 | 确定 | 必发生，先备份 |
| 刷 lk 变砖 | 高 | lk 整包替换 bootloader，起不来只能 BROM/售后 |
| 无限重启/卡 fastboot | 中 | 有恢复脚本，见上 |
| 丢基带 | 中 | **提前存 IMEI**，9008 可写回 |
| 系统升级失效 | 低 | 关闭系统更新 |
| 小米售后拒保 | 中 | 解锁机进过保可能被拒 |
| 临时root 中途重启 | 低 | 重启即失效，流程中别重启 |
