# REDMI K90 字库查询指南

> 用途：判断 UFS 闪存厂商（东芝 / 三星 / 海力士 / **铠侠**）。
> **若查出是铠侠，所有「免授权引导」方案立即停止使用** —— 会变成大黑砖。

---

## 方法一：澎湃工具箱（官方，最推荐）

酷安各教程一致的首选方法。

### 步骤

1. 手机应用商店搜 **「澎湃工具箱」**（小米官方出品，包名 `com.miui.toolbox`）
2. 打开 → 找到 **「设备硬件」**（部分版本叫「硬件信息」/「设备信息」）
3. 页面往下滑到 **「内存存储」** 区块
4. 找 **「ROM 存储」** 这一行，看 **「厂商」** 和 **「型号」**

### 怎么读

参考酷安教程里的真实截图（小米 MIX Fold 3）：

```
内存存储
├── RAM 内存
│   ├── 厂商      海力士 (Hynix)
│   ├── 大小      16GB
│   └── 代码      0x06
└── ROM 存储
    ├── 厂商      三星 (Samsung)      ← 看这个
    ├── 大小      1024GB
    ├── 型号      KLUGGARHHD-B0G1    ← 和这个
    └── 代码      0x01ce
```

**判断规则**

| 厂商显示 | 结果 | 能不能用免授权引导 |
| --- | --- | --- |
| 三星 (Samsung) | e.g. `KLUGGARHHD-B0G1` / `KMU8E1GXQ-M0B` | ✅ 可以 |
| 东芝 (Toshiba) | e.g. `THGBMUFGC8N3L` | ✅ 可以 |
| 海力士 (Hynix) | e.g. `HAFL1TBHDBBC` | ✅ 可以 |
| **铠侠 (Kioxia)** | e.g. `THGMAJGCBEXJ1` | ❌ **立即停止** |

> 铠侠的英文名也写作 **Toshiba Kioxia**，某些工具箱会混着显示两个名字，
> **型号开头是 `THG` / `THGBM` / `THGMA` 的基本都是铠侠**。
> 如果厂商栏写「东芝」但型号是 `THG...` 开头，**按铠侠处理**。

### 备选：逸风工具箱

如果澎湃工具箱的「设备硬件」里 ROM 厂商显示不出来，
用 **逸风工具箱（小米刷机工具箱）** 抓日志，
在日志里搜 `rom` / `flash` / `ufs`，找厂商字段。

## 方法二：ADB 直接读（不用装工具箱）

你已经临时root了，走 shell 更直接。

### 用 Termux

```bash
# 列出所有分区块设备
ls -l /dev/block/by-name/ | grep -i -E 'ufsc|ufs'

# 读 UFS 厂商字符串（需要 root）
su -c 'cat /sys/class/scsi_host/host0/device/vendor 2>/dev/null'
su -c 'cat /sys/class/scsi_host/host0/device/model 2>/dev/null'

# 或读 sysfs 的 udev 属性
su -c 'cat /sys/devices/platform/soc/1b17000.usb/*/ufshcd*/device/../../* 2>/dev/null'
```

> 上面几组路径在不同内核上位置不同，任一能出结果即可。

### 用 ADB（连电脑）

```powershell
adb shell su -c "cat /sys/class/scsi_host/host0/device/vendor"
adb shell su -c "cat /sys/class/scsi_host/host0/device/model"
```

### 用 `lsblk`（较新的内核）

```bash
su -c 'lsblk -o NAME,VENDOR,MODEL,SIZE /dev/block/sda'
```

输出里的 `VENDOR` 就是闪存厂商。

## 方法三：KernelSU / Magisk 里看

你已经有临时root，装了 KernelSU 的话：

1. KernelSU 管理器 → **超级用户** → 授权 **Termux** 或 **Shell**
2. 用 Termux 执行方法二的命令

---

## 方法四：拆机看（最土但最准）

如果上面都读不出来：
1. 查拆机视频确认 K90（annibale）的存储芯片型号位号
2. 对比你的 `getprop ro.boot.*` 输出

一般不建议，走到这步说明前面方法应该已经能读出来。

## 读到的信息请记下

```
ROM 厂商：__________
ROM 型号：__________
RAM 厂商：__________
```

同时用 `adb shell getprop` 存一份完整快照备用：

```powershell
adb shell getprop > k90_getprop.txt
adb shell cat /proc/partitions > k90_partitions.txt
adb shell uname -a > k90_uname.txt
```

## 拿到结果后的分支

### 如果是 铠侠（Kioxia）

- ❌ **不要用免授权引导**（会大黑砖）
- ❌ 不要用 9008 免授权写 abl
- ✅ 可选方案：
  1. **9008 写工程 abl + 授权版引导**（需要付费工具授权，如 MTK v6 / 刷机匣付费版）
  2. **官方社区申请解锁**（绑账号等 7 天，但小米现在限制多，成功率低）
  3. **找酷安接单商家**（feed 74890471 梵依 60 元一条龙，明确接 K90 8e 机型）
  4. 走 **9008 写解锁 lk**（不用免授权引导，只写 lk，不需要引导文件）

### 如果是 东芝 / 三星 / 海力士

- ✅ 直接走 **QC解锁BL工具 v2.5Plus**（路线 A）
  - 临时root → KSU 授权 shell → 一键解锁
  - 8E 机型 v2.0+ **不需要刷包**
- ✅ 或走 **Termux 自解锁**（路线 B，不需要电脑）
- ✅ 或走 **伤心工具箱 v1**（feed 75091185，手机 OTG 给手机解锁，无需电脑）

## 附：为什么字库这么重要

酷安原话（feed 72612030 / 71670934）：

> ● 铠侠字库请不要使用免授权引导（用了变大黑砖），我也不知道这个机型是否有铠侠的闪存，
> 所以最好还是查一下，下载澎湃工具箱/逸风工具箱，抓取日志查看存储信息，
> 是铠侠就不要继续操作了，不是铠侠就继续操作
> ● 如果是铠侠字库请立即停止操作

原因：免授权引导（EDL 免授权 payload）针对的是**东芝/三星/海力士**的
UFS 实现，铠侠的 UFS 控制器实现不同，引导文件写进去会直接砖。
