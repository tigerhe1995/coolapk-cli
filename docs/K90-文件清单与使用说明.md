## 三、执行顺序

```
□ 1. 拿到 QC 工具箱密码，双击 exe 解压
□ 2. 运行工具箱 → Tools\Driver → 一键安装安卓驱动（不用重启）
□ 3. 手机开 USB 调试 + USB 调试（安全设置）
□ 4. 装一个 KernelSU/SukiSU 管理器（自带 libksud.so）
□ 5. 临时root 工具提权成功
□ 6. KSU 超级用户里给 shell 授权
□ 7. QC 工具箱 → 选机型 K90（8E系）→ 走「已有root」路线 → 一键解锁
      （花屏/白屏 10 秒，别拔线 → 手动进 fastboot：音量下+开机键）
□ 8. fastboot getvar unlocked → 必须是 unlocked=yes
□ 9. 线刷官方包：
      cd F:\04.DSH\work\k90-root\files\03-官方线刷包\已解压\annibale_images_OS4.0.6.0.XPKCNXM_17.0
      flash_all.bat
      ★ 绝对不能选 flash_all_lock.bat
      ★ 路径不能有空格和括号
□ 10. 刷 KernelSU（工具箱可能会引导刷，或手动刷 init_boot）
□ 11. 立刻备份字库（必做）
□ 12. 关闭系统更新 + 装隐藏模块（ZygiskNext）
□ 13. 重启验证 root 持久
```

## 四、应急回退

| 现象 | 处理 |
|---|---|
| 卡在 fastboot 起不来 | `fastboot flash partition:4 images/gpt_both4.bin`（工程小包里）<br>`fastboot erase userdata`<br>`fastboot erase metadata`<br>`fastboot reboot` |
| 无限重启进不了系统 | `fastboot --set-active=a` / `--set-active=b` 切换槽位<br>或关机键+音量上进 recovery 清数据 |
| 9008 模式 | 用 `02-K90工程小包` 里的 rawprogram0-5.xml + abl.elf，走 OneToolBox 写分区 |
| 彻底救砖 | 需要 9008 工程线 + OneToolBox，或联系作者远程 |
